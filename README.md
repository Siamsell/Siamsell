### Distributed Microservices Platform
*Resilient by design.*

Six service instances deployed across nine servers, with service discovery, health monitoring, load balancing and fault tolerance. Services communicate asynchronously through events, and RabbitMQ keeps independent databases in sync while reducing coupling.

`Node.js` · `Traefik` · `Consul` · `RabbitMQ` · `MySQL` · `Docker`

### UMBB Exam Management System
*From constraints to timetable.*

A web application that generates exam schedules automatically while respecting working days (Saturday to Thursday), level-based time slots (L1 to M2), public holidays, and optimal room and invigilator allocation. Includes secure role-based access (Admin, Dean, Vice-Dean, Department Head, Professor, Student), a validation workflow for academic managers, and an interactive KPI dashboard.

`Python` · `Streamlit` · `PostgreSQL (Neon)` · `Plotly` · `Pandas` · `SHA-256`
